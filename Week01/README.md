# Reflection
During this first week's laboratory activity, I learned that being a successful System Administrator goes beyond just knowing how to configure servers; it requires strict organization, proper documentation, and a professional digital footprint. By setting up Git, GitHub, and VirtualBox, I now have a centralized and controlled environment where I can safely test configurations and track my progress. 

These tools will heavily support my development as a future IT professional. Virtualization tools like VirtualBox will allow me to simulate real-world server environments without risking my main operating system, while having a structured repository ensures that all my scripts, configurations, and documentation are safely backed up and version-controlled. Moving forward, maintaining this repository will not only help me track my academic growth but also serve as a concrete showcase of my technical skills for future projects and evaluations.
